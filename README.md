# Issue Reports

Report kỹ thuật, nghiệp vụ tổ chức theo mã ticket.

## Cấu trúc

```
<MÃ-TICKET>/
├── dev-report-vi.md   # Dòng thời gian xử lý ticket, bản kỹ thuật (có code) — Tiếng Việt
├── dev-report-en.md   # Cùng nội dung với dev-report-vi.md — bản tiếng Anh
├── bc-report-vi.md    # Cùng dòng thời gian, viết lại thuần nghiệp vụ (không code) — Tiếng Việt
└── bc-report-en.md    # Cùng nội dung với bc-report-vi.md — bản tiếng Anh
```

Mỗi ticket đúng 1 folder duy nhất, cập nhật nối thêm khi công việc tiếp
tục qua nhiều buổi — không bao giờ tạo folder mới cho cùng 1 ticket.
Nội dung `-vi` và `-en` cùng loại (dev/bc) luôn khớp nhau 1:1, chỉ khác
ngôn ngữ.
