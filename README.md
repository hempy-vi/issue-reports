# Issue Reports

Report kỹ thuật, tổ chức theo mã ticket.

## Cấu trúc

```
<MÃ-TICKET>/
├── dev-report.md   # Dòng thời gian xử lý ticket, bản kỹ thuật (có code)
└── bc-report.md    # Cùng nội dung, viết lại thuần nghiệp vụ (không code)
```

Mỗi ticket đúng 1 folder duy nhất, cập nhật nối thêm khi công việc tiếp
tục qua nhiều buổi — không bao giờ tạo folder mới cho cùng 1 ticket.
